# Chaos in Microbial Models

This repo contains example code used to the generate the graphs in the supplementary materials of . 

The file *parameter_collection.jl* contains the parameters used to generate the bifurcation diagrams that appear in the main text and supplemental material.

The file *utility_functions.jl* contains functions use to produce the diagrams and example loss function constructors.

The file *cr_bifurcation_diagrams.ipynb* is a Jupyter notebook with an example script to generated a bifurcation diagram of the Consumer Resource model.

The file *glv_bifurcation_diagrams.ipynb* is a Jupyter notebook with an example script to generated a bifurcation diagram of the generalized Lotka-Volterra model.
